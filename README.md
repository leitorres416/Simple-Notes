# 📝 Simple Notes
A simple but versatile and gorgeous note-taking app. Write down whatever you want, your notes will be there for you whenever you need them!

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ✨ Features
- 'Add New Note' button, your notes will be stored locally so they won't be lost when you refresh or close the app.
- 'Edit Note' and 'Cancel' button. Any changes made will be saved.
- ☀️ Light/Dark Mode toggle button 🌙
- Clean, fully responsive interface.
