# Simple-Notes 🗒️
Write down whatever you need to remember, your notes will be there for you as they're stored locally and won't be lost when you refresh or close

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ✨ Features
- 'Add New Note' button. 📝
- 'Edit Note', 'Delete' and 'Cancel' buttons. Any changes made will be saved.
- ☀️ Light/Dark Mode toggle button 🌙
- Clean, fully responsive user interface. 📱
